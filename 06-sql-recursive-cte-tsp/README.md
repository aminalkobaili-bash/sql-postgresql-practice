# 06 — Recursive CTE: Traveling Salesman Problem

**Задача:** на графе из 4 городов найти самый дешёвый и самый дорогой маршрут, который выходит из `a`, проходит каждый город ровно один раз и возвращается в `a`. Решить средствами SQL, без процедурного кода.
**Стек:** PostgreSQL, psql, `WITH RECURSIVE`, arrays

## Что сделано
- Создал таблицу рёбер `routes (point1, point2, cost)`: составной `PRIMARY KEY`, `CHECK (point1 <> point2)`, симметричная стоимость в обе стороны.
- Рекурсивный CTE строит все пути из `a` и хранит пройденные вершины в массиве `tour`.
- Повторное посещение города отсекается условием `r.point2 <> ALL(p.tour)`.
- Замыкание цикла: путь из 4 вершин + ребро обратно в `a`.
- Отбор минимума (ex00) и минимума + максимума через `UNION ALL` (ex01).

## Упражнения

## Граф

| | a | b | c | d |
|---|---|---|---|---|
| **a** | — | 10 | 15 | 20 |
| **b** | 10 | — | 35 | 25 |
| **c** | 15 | 35 | — | 30 |
| **d** | 20 | 25 | 30 | — |

## Как запустить

```bash
psql -d pizza_db -f src/ex00/ex00.sql
psql -d pizza_db -f src/ex01/ex01.sql
```

ex00 создаёт таблицу `routes`, ex01 её использует. От схемы пиццерий модуль не зависит.

## Результат
- Минимальная стоимость — 80: `a → b → d → c → a` и обратный обход `a → c → d → b → a`.
- Максимальная стоимость — 95.
- Решение не привязано к числу вершин, кроме условия длины `array_length(p.tour, 1) = 4`.
