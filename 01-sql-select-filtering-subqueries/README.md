# 01 — SELECT, Filtering & Subqueries

**Задача:** выбрать данные о клиентах, пиццериях и заказах по условиям, не используя JOIN — только фильтры, вычисляемые поля и подзапросы.
**Стек:** PostgreSQL, psql

## Что сделано
- Фильтрация по строкам, диапазонам и датам: `WHERE`, `BETWEEN`, операторы сравнения, `lower()`.
- Вычисляемые поля: конкатенация строк (`||`), условная логика `CASE`.
- Данные из связанных таблиц через коррелированные подзапросы в `SELECT` и подзапрос в `FROM` вместо JOIN.
- Одна задача решена двумя способами: через `>=`/`<=` и через `BETWEEN` (ex02).

## Упражнения

| # | Что делает | Ключевое |
