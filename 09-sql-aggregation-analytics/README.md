# 09 — Aggregation & Analytics

**Задача:** посчитать метрики активности клиентов и пиццерий: посещения, заказы, цены, рейтинги, разрезы по адресам.
**Стек:** PostgreSQL, psql

## Что сделано
- Агрегаты `COUNT`, `AVG`, `MIN`, `MAX` с `GROUP BY` по одной и двум колонкам.
- Топ-N через `ORDER BY … LIMIT` в подзапросах, объединённых `UNION ALL` с меткой `action_type`.
- Суммирование метрик из двух источников через `FULL JOIN` + `COALESCE`, чтобы не терять пиццерии без визитов или заказов (ex03).
- Фильтрация агрегатов через `HAVING` без `WHERE`.
- Округление `ROUND`, приведение к `NUMERIC` в вычисляемой формуле (ex09).

## Упражнения

| # | Что делает | Ключевое |
|---|---|---|
| [ex00](src/ex00/ex00.sql) | число визитов по `person_id` | `COUNT`, `GROUP BY` |

| [ex02](src/ex02/ex02.sql) | топ-3 пиццерии по визитам и по заказам | подзапросы с `LIMIT`, `UNION ALL` |

| [ex04](src/ex04/ex04.sql) | клиенты с > 3 визитами | `HAVING` |
| [ex05](src/ex05/ex05.sql) | уникальные имена заказчиков без `GROUP BY` | `DISTINCT` |
| [ex06](src/ex06/ex06.sql) | заказы, средняя/макс/мин цена по пиццериям | `AVG`, `MAX`, `MIN`, `ROUND` |

| [ex08](src/ex08/ex08.sql) | число заказов по адресу клиента и пиццерии | `GROUP BY` двух колонок |
| [ex09](src/ex09/ex09.sql) | формула по возрасту vs средний возраст по адресу | вычисляемые агрегаты, `::NUMERIC` |
