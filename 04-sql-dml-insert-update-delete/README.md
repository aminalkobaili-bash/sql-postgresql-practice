# 04 — DML: INSERT, UPDATE, DELETE

**Задача:** проанализировать посещения и заказы (ex00–ex06), затем изменить данные: добавить позиции меню, визиты и заказы, обновить цены, удалить тестовые записи (ex07–ex13).
**Стек:** PostgreSQL, psql

## Что сделано
- Многотабличные выборки и операции над множествами с дубликатами (`EXCEPT ALL`, `UNION ALL`) и без них.
- `INSERT` с ключами и внешними ссылками из подзапросов (`MAX(id) + 1`, `id` по имени) вместо захардкоженных значений.
- Массовая вставка `INSERT … SELECT` + `generate_series` — заказ для каждого клиента одним запросом.
- `UPDATE` с расчётом (−10% к цене) и `DELETE` для отката тестовых данных.
- В ex07–ex10 есть закомментированные `DELETE` для отката каждого шага.

## Как запустить

```bash
psql -d pizza_db -f src/ex00/ex00.sql
```

ex07–ex13 меняют данные и зависят друг от друга: запускать по порядку на чистой БД. Сброс БД — в [корневом README](../README.md#как-запустить).

## Результат
- 7 аналитических запросов и 7 DML-операций.
- Вставки не зависят от текущих `id`: ключи и ссылки вычисляются подзапросами.
- ex13 откатывает изменения ex07, ex11 и ex12.
